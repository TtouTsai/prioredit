# Data setup

No patient data is redistributed in this repository. Every corpus below must be obtained from its
own source under its own terms.

## What ships here

| path | content | why it is safe to release |
|---|---|---|
| `data/labels/prior_chexpert_labels.json` | 14-way CheXpert label states for the prior report, 1337 studies | label states only (`pos`/`neg`/`unc`/`none`), keyed by study id — no report text |
| `data/labels/gt_chexpert_labels.json` | same, for the current ground-truth report | as above |
| `data/labels/official_labels_by_hash.json` | labeler output cached by text hash | hashes + label states, no text |
| `data/generations/*.json` | reports generated by our system and the baselines | model output, not patient records |
| `data/finding_confidence.json` | per-study, per-finding confidence `c_f(I)` | scalar log-prob differences |

## What you must obtain

| resource | source | used for |
|---|---|---|
| **MIMIC-CXR** (reports) + **MIMIC-CXR-JPG** (images) | PhysioNet, credentialed access + Data Use Agreement | prior/current report text, current images |
| **MIMIC-RG4** scenario splits | released with LLM-RG4 | the evaluation split, the `sn`/`sw` scenarios, prior-report pairings |
| **MS-CXR-T** | PhysioNet (released with BioViL-T) | the direction probe (App. D) |
| **Chest ImaGenome** | PhysioNet | region-level analyses only; not needed for any paper number |
| **LLM-RG4** checkout + checkpoint | the authors' release | the image-only base model (`sn`) |
| **CXRMate** (`aehrc/cxrmate`), **MLRG** (`MK-runner/MLRG`) | Hugging Face | baseline generations |
| **CheXbert** checkpoint, **CXR-BERT** (`BiomedVLP-CXR-BERT-specialized`) | as published | presence metric; direction probe |
| **CheXpert labeler** (dockerized) | `stanfordmlgroup/chexpert-labeler` | the authoritative rule labeler behind TCA |

## Expected layout

Point `PRIOREDIT_DATA` at a root arranged like this (only the parts a given script needs must
exist):

```
$PRIOREDIT_DATA/
  mimic-cxr-reports/files/...                  MIMIC-CXR free-text reports
  mimic-cxr-jpg/files/...                      MIMIC-CXR-JPG images
  mimic-cxr-2.0.0-metadata.csv                 study dates/times, for prior pairing
  mimic_rg4/sw_single_view_with_prior.json     MIMIC-RG4 sw scenario
  ms-cxr-t/ms-cxr-t-.../                       MS-CXR-T release directory
  chest-imagenome/chest-imagenome-dataset-1.0.0/
  hf-cache/                                    Hugging Face cache (HF_HOME)
```

and `PRIOREDIT_LLMRG4` at the LLM-RG4 checkout:

```
$PRIOREDIT_LLMRG4/
  data/swcmp/annotation.json     evaluation split + prior report text per study
  hf/                            cached encoders (rad-dino, CXR-BERT, chexbert.pth, bert-base-uncased)
  save/                          inference outputs
```

## The CheXpert labeler

TCA's ground truth is the **official Stanford CheXpert rule labeler**, run independently on the
prior report and the current ground-truth report. `scripts/metric/chexpert_label.py` drives the
dockerized labeler and writes the `{id: {finding: state}}` files shipped in `data/labels/`, so
that step can be re-run from scratch once you have the report text.
